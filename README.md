## The line

> My fridge hums like it pays rent, but the only thing it keeps cold is a jar of pickles older than my last three relationships.

## How it works

`main.py` (Python 3, standard library only, no network) writes that single
line — 126 characters — to `/output/entry.txt`, exactly the same bytes on
every run. Before writing, it asserts the entry is one line, one complete
sentence, and within the 200-character limit.

Run it:

```sh
python3 main.py
```
